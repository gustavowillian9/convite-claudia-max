# Convite de Casamento — Claudia Cristina & Max Alexandre

Projeto estático em HTML, CSS e JavaScript com uma experiência de abertura cinematográfica.

## Arquivos
- `index.html`: estrutura das três cenas.
- `style.css`: identidade visual, transições e animações.
- `script.js`: controla a abertura e a navegação.
- `assets/envelope-fechado.png`: referência do envelope fechado.
- `assets/envelope-aberto.jpg`: referência do envelope aberto.
- `assets/convite.jpg`: arte do convite.

## Publicar no Render
Crie/edite um serviço Static Site conectado ao repositório GitHub.

- Root Directory: `convite-casamento` se os arquivos estiverem dentro dessa pasta; deixe vazio se estiverem na raiz.
- Build Command: vazio.
- Publish Directory: `.`

## Observação
As animações são feitas por CSS e JavaScript. As fotografias de referência são usadas como cenas estáticas; não há vídeo.
